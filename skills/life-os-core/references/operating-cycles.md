# Operating Cycles

Cycles 是正式逻辑集合和 Life OS 的运行系统。四层关系固定为：

```text
Daily -> Weekly -> DuoCycle -> Annual
```

Daily、Weekly、DuoCycle、Annual 是同一集合中的四个固定种类。它们不保存父子 Relation；同一日期或时间区间的包含关系决定展示和聚合，高层 Cycle 可后建或不存在。

## Daily Loop

### 晨间启动：约 3 分钟

1. 新建或打开今天的 Daily Entry。
2. 填写简短晨间记录，例如当前状态和今天最想做成的一件事。
3. 查看 Top Priorities Today，从 3-5 个候选中确认 2-3 个今日重点。
4. 不重新做战略规划，直接开始 `priority_1` Action。

### 白天执行与捕获

1. 主要停留在 Focus Zone，按 Compact 排序执行 Actions。
2. 完成 Action 后更新为 `done`；开始处理时可更新为 `in_progress`。
3. 临时任务、会议、跑腿或事件通过 Quick Add 进入 Actions；立即设置 Do-Date，并连接 Project 或 Routine。
4. 文章、视频、文件、会议记录或灵感进入 Neurobits，初始状态为 `queue`。
5. 不在白天展开 Alignment 规划；需要重新判断的事项进入 `waiting` 并设置未来 Do-Date。

### 晚间闭店：约 5 分钟

1. 在 Daily Entry 写简短晚间复盘和必要 Tracking Fields。
2. 打开 Month，逐项处理今天未完成的 Actions。
3. 明天做则把 Do-Date 移到明天；本周做则移到本周稍后；不再重要则删除；等待或暂缓则改为 `waiting` 并设置重看日期。
4. 确认明天的 2-3 个重点，标出 `priority_1` 与 `priority_2`。
5. 为值得记住的 Action、Neurobit、GPR 或 Daily 勾选 `Notable`。

晨间与晚间维护合计建议不超过 10 分钟。

## Weekly Loop：约 20-30 分钟

固定四步：

### 1. Clear Inboxes

- 处理 `queue` Neurobits：连接 Topic，并按需要连接 GPR；推进到 `in_progress` 或 `finished`。
- 处理新增 Actions：确认 Do-Date、Project/Routine 上级、Priority、Type、Category 及必要关系。
- 不保留脱离 Project/Routine 的 Action。

### 2. Pipeline Review

- 检查 Active Goals 及其 Project/Routine 是否继续推进愿景。
- 检查卡住的 active Projects；必要时新增 1-2 个具体 Actions。
- 检查 active Routines 是否产生下一周需要执行的 Actions。
- 检查到期未完成 Actions，重新分配 Do-Date。
- 检查 Revisit/Waiting；等待过久时创建有 Do-Date 的跟进 Action。
- 查询 Period 落入当前 Weekly 范围的 Daily，检查本周记录；Auto-Data Summary 由周期范围聚合，不维护子周期 Relation。

### 3. Mark Notable

- 浏览本周完成的 Actions、重要 GPR 进展、优秀 Neurobits、相关 People 互动和 Daily 记录。
- 选出最触动或最值得记住的 1-2 项，勾选 `Notable`。
- 确认它们能在当前 Annual 的 Remembrance Collection 中出现。

### 4. Plan Next Week

- 选择下周 1-3 个重点 Projects/Routines。
- 把下一步拆成 Actions，并把 Do-Date 分配到具体日期。
- 检查下周 Actions 是否服务于当前 DuoCycle 的 2-3 个核心 Active Goals。
- 完成后在 Weekly 正文记录复盘结论。

## DuoCycle Loop：约 1 小时

DuoCycle 覆盖约两个月，一年形成六个周期。

1. 打开 Alignment Zone 的 Active Goals 与当前 DuoCycle。
2. 评估过去约 60 天的 Goal：完成则改为 `completed`；未完成则决定延续、改期、暂停或放弃。
3. 检查每个 Active Goal 是否仍连接有效 Life Aspiration，并沿 Parent Pillar 回到长期方向。
4. 查询 Period 落入当前 DuoCycle 的 Weekly，并通过周期范围和正向上下文关系查询 Actions、Neurobits、GPR、Tracking Fields、Auto-Data Summary 和 Notable 内容。
5. 为下一个 DuoCycle 激活 2-3 个核心 Goals，并建立支撑的 Projects、Routines 与首批 Actions。
6. 为下一个 DuoCycle 写入覆盖范围；Weekly 与 Annual 的归属由日期范围查询派生，不回填关系。
7. 写下结果、学习和下一轮调整。

采用 DuoCycle 作为中期节奏；不要再引入与其重复的 Monthly 或 Quarterly 运行链。

## Annual Loop

1. 打开 Knowledge Zone 的当年度 Remembrance Collection，回看过去 12 个月所有 `Notable == true` 的源对象。
2. 按 Actions/GPR、Neurobits/Topics、People、Cycles 回顾重大成果、优质知识、重要关系和日记反思。
3. 查询 Period 落入当前 Annual 的 DuoCycles，汇总结果、学习、Tracking Fields 与 Auto-Data Summary。
4. 检查 Pillars 是否仍表达长期人生领域、核心价值观和长期定位。
5. 检查 Life Aspirations 是否仍有情感意义，Goals 是否具体、可衡量且有时间点。
6. 决定下一年度延续、停止、暂停或新激活的 Goals，并建立新的 Annual 与首个 DuoCycle。
7. 完成年度总结；值得记住的 Annual 本身可勾选 `Notable`。

## 运行恢复

中断一周或积压时，不重建系统。先处理所有到期未完成 Actions：重新设置 Do-Date、转为 `waiting` 或删除；再恢复当前 Daily 和 Weekly。关系、状态、Cycle 与 Remembrance 仍沿八集合继续运行。
